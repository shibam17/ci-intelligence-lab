## Try this project with Harness CI

Want to build and test this Java project using a CI pipeline without writing pipeline YAML from scratch?

I used this repository to demonstrate how Harness can detect a Java/Maven project, generate a CI pipeline, run tests, and optionally build and push a Docker image.

**Follow the hands-on tutorial:** [From Git Repo to Docker Image: Building Your First CI Pipeline in Harness](https://www.harness.io/blog/harness-ci-pipeline-tutorial-build-push-docker)

### Get your first CI pipeline running

1. Fork this repository to your GitHub account.
2. Create a Harness account, subject to free-tier eligibility.
3. Start a new CI build pipeline and connect your GitHub account.
4. Select your fork and let Harness generate the initial pipeline.
5. Execute the pipeline and confirm that the build and tests pass.

Once your first build works, follow the tutorial to add Docker image building and pushing.

**Expected outcome:** A successful CI pipeline execution using your own fork of this repository.

Have trouble with the setup? Open a GitHub issue describing where you got stuck.
